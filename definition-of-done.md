# Definition of Done — Team 14

A story is **Done** only when all of the following are true:

- [ ] Code is on a feature branch and merged to `main` through a pull request
- [ ] The pull request is reviewed and approved by at least one other team member
- [ ] Unit tests are written (TDD) and pass locally and in CI
- [ ] Gherkin scenario added for stories with business rules
- [ ] CI pipeline (tests + linter) is green on the pull request and on `main`
- [ ] Linter reports no errors
- [ ] All acceptance criteria are met and demonstrated
- [ ] No known bugs; errors show clear messages
- [ ] Uses test data only (no real personal data)
- [ ] README is updated if install, run or test steps changed
- [ ] Jira story moved to Done with the Product Owner's acceptance in the Sprint Review
